## 2. 料金・決済の確認

### 2.1 スタッフ別料金（現在のデフォルト例）
- 管理画面の「料金設定」で変更可能。Supabase の `staffs` テーブルまたはローカル保存。
- **打ち合わせで確認すること**
  - 各スタッフの表示料金（例: 60分あたり）で正しいか。
  - 初診料・延長料など別料金の扱い（メモで対応するか、仕組みを変えるか）。

### 2.2 決済方法
- 管理画面で「現金・クレジット・PayPay・チケット・ツケ払い・保険」などから選択可能。
- **打ち合わせで確認すること**
  - 実際に使う決済方法だけに絞るか、すべて使うか。
  - ツケ払い・保険の「決済日」をいつ入力するか（当日・月末など）。

## 5. 日常運用のルールづくり

### 5.1 管理画面の見方・更新タイミング
- **打ち合わせで確認すること**
  - 毎日、誰が・いつ、予約一覧を確認するか。
  - 新規予約の Realtime 通知（画面上のバー・通知音）を、誰がどの端末で受け取るか。
  - 予約が入ったときの院内の共有方法（声かけ・チャット等）。

### 5.2 ブロックの使い方
- 休暇・研修・臨時休業は「ブロック」または「一括ブロック」で予約不可にする。
- **打ち合わせで確認すること**
  - ブロックは何日前までに入力するか。
  - 理由（「休暇」「学会」等）の入力ルール。

### 5.3 患者検索・履歴
- 名前・電話番号で検索可能。過去の予約・キャンセルも一覧で見られる。
- **打ち合わせで確認すること**
  - 検索結果（個人情報）を共有するときの注意（見せる範囲・端末の置き場所）。

### 5.4 ダッシュボード・CSV
- 売上・予約数・決済別集計・スタッフ別実績・グラフを表示。期間を指定して CSV 出力可能。
- **打ち合わせで確認すること**
  - 売上数字の確認は誰が・どの頻度で行うか。
  - CSV は経理・確定申告用に使うか。使う場合の出力頻度と保管方法。

### 5.5 小口経費
- 入金・出金を日付・金額・種別・カテゴリ・担当・メモで登録可能。
- **打ち合わせで確認すること**
  - 経費のカテゴリをどう分けるか（共通リストを作るか）。
  - 誰が入力し、誰が確認するか。論理削除した場合のルール。

## 7. 公開前の技術・表示チェック

- [ ] **Supabase**: 本番用 URL・キーが設定されているか。`staffs` テーブル・料金が正しく登録されているか。
- [ ] **LINE LIFF**: LIFF ID が本番用か。予約画面が LINE 内・ブラウザの両方で開けるか。
- [ ] **営業時間・定休**: `admin.html` と `index.html` の `STAFF_HOURS` / `WORK_HOURS` と `WEEKLY_OFF` が実態と一致しているか。
- [ ] **スタッフ名**: `STAFFS` 配列が両方のファイルで同じか。スタッフの追加・削除があれば両方修正。
- [ ] **電話番号・LINE リンク**: 予約画面の連絡先が正しいか。
- [ ] **テスト予約**: スタッフが患者役で 1 件予約〜キャンセルまで実施し、管理画面で表示・編集・キャンセルができるか。
- [ ] **通知**: 新規予約時に管理画面で通知バー・音がなるか確認。

## 8. 打ち合わせ後のアクション例

1. **運用ルール** → 決まった内容を簡単にメモ（1枚の運用メモでも可）。
2. **営業時間・定休・スタッフ名** → 変更があれば開発者または担当者が `admin.html` / `index.html` を修正。
3. **料金** → 管理画面の料金設定または DB で反映。
4. **連絡先** → 変更があれば `index.html` の電話・LINE リンクを修正。
5. **管理者アカウント** → Supabase で管理者用ユーザーを作成し、ログインできることを確認。
6. **公開日** →  LINE やホームページで予約開始を案内する日を決める。
